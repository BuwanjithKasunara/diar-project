# Architecture decision records

Use sequential `NNNN-short-title.md` filenames. Each record includes title, date, status, context, decision, alternatives, consequences, and related documentation. Statuses: Proposed, Accepted, Rejected, Superseded.

Preserve accepted decisions. Changed decisions get a new record with reciprocal supersession links. Do not invent historical dates. Routine fixes do not require ADRs unless they change meaningful architecture, algorithm, privacy, persistence, or compatibility policy.
