# 0006: Privacy-aware role reasoning

Date: 2026-09-27  
Status: Accepted

## Context

Uniform GitHub expectations and public-showcase suggestions can conflict with career goals or privacy preferences.

## Decision

Use role-specific evidence expectations and privacy-compatible alternatives. Treat contact detection separately from verified public exposure; interpret fuzzy scores as evidence alignment.

## Alternatives

One rule set for all careers; suppress all recommendations for privacy-focused users.

## Consequences

More policy cases require regression coverage. Curated role expectations are assumptions, not validated hiring standards.
