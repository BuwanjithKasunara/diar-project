# Local demonstration

Follow [setup](../development/setup.md).

1. Choose career and visibility.
2. Supply an unlocked text PDF, GitHub username (not a URL), or pasted profile text. The interface displays limits fetched from the backend; defaults are 5 MB, 30 PDF pages, and 50,000 pasted characters. Identify pasted-text visibility only when known.
3. Analyse and inspect source statuses/warnings.
4. Read assessment and evidence; “not assessed” means unavailable information.
5. Review separate suggested actions. Effort units are relative, and steps do not certify competence.
6. Save only if retention on this computer is wanted.
7. Use History to open/delete reports.

For GitHub failures inspect warnings and retry or supply another source. Start the backend if offline. A failed later request preserves the previous result. Older reports may omit evidence/plans. Use synthetic data for demonstrations.
