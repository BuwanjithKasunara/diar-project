# Scope and requirements

The improvement phase retains AI Engineer, Software Engineer, Data Scientist, Researcher, and Entrepreneur, with Fully Public, Semi-Public, and Privacy Focused visibility.

- R1: Context-aware extraction with evidence/assertion status. Verify positive, negated, planned, ambiguous, and typo examples.
- R2: Independent source states and unknown assessments. Verify missing, partial, failed, and short inputs.
- R3: Role-aware benchmarks and privacy-compatible actions. Verify all career/visibility combinations.
- R4: Bounded uniform-cost planning. Verify exhaustive small-state comparisons and fallbacks.
- R5: Validated API and explicit persistence. Verify isolated API/database tests and legacy retrieval.
- R6: Accessible assessment, evidence, plan, and history views. Verify browser/keyboard workflows.
- R7: Repeatable setup, tests, and documentation. Verify setup and documentation links.

See [handover](handover.md) and [verification results](../testing/results/development-verification.md) for implementation evidence.

Neural training, React migration, accounts, hosting, OCR, and automated LinkedIn collection are deferred. Broader user evaluation and final report/slides/video follow this phase.
